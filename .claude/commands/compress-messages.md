---
description: Rewrite the hook's emitted message files in caveman style, meaning intact
---

Compress the message files this binary emits. They are `include_str!`ed, so nothing but
the text changes.

In scope — every `*.txt` beside a check under `src/checks/`:

- `src/checks/design_rationale/audit-ask.txt` — the per-draft audit refusal. Fires once
  per draft and stays in the session transcript, so it is the one worth the effort.
- `src/checks/glab-traps.txt` — the traps the shipped glab skill omits. Fires once per
  session, already terse; only obvious fat comes out.

Never touched by this command:

- `src/checks/design_rationale/rules.md`, `judge.rs` and `overlap.rs` prompts. Those are
  read by the local judge model and were tuned against a labelled corpus; rewording them
  is measured with `./probe-judge.sh` over that corpus, never compressed blind.
- `src/rules.rs`. Its own flat style is stated in the module doc and it is regenerated by
  `make release`.
- Reasons still living as string literals in a check. Under a kilobyte they read better
  beside the branch that emits them; extract one only when it grows past that.

Rules, from the caveman skill: drop articles, filler, hedging, connective fluff, and any
sentence that explains rather than states. Fragments are fine. Never drop a negation
(not/never/no/only/except), a number or a unit. Never invent an abbreviation — the
tokenizer splits it the same and the reader still decodes it.

Survives verbatim: command words, flags, paths, environment variables, marker names,
backticked spans, and the name of every tool a message tells the reader to use instead.

These are instructions to a model that has to act on them, so an instruction lost is worse
than a token kept. After rewriting, read each file back and check every instruction in the
original is still there — same order, same force.

Then:

    make -j check
    ./probe.sh   # with a command that fires each message you touched

and report the byte delta per file.
